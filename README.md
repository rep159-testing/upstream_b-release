# upstream_b

Middle of the three-package chain in the `upstream` distribution of the
[REP 159](https://github.com/openrobotics/reps/pull/32) test harness:
`upstream_a` ◄ `upstream_b` ◄ `upstream_c`. Summarizes an XML document through
`upstream_a`. Plain CMake package, no ROS dependency.

Index and distribution files: https://github.com/rep159-testing/rep159-rosdistro
